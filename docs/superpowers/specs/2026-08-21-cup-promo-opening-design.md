# 第2回J.STYLE杯 期間限定プロモーション（トップページ）— 設計

作成日: 2026-08-21

## 目的

第2回J.STYLE杯（2026年12月26日・27日／申込締切11月13日）の参加チームを募るため、トップページのファーストビューに期間限定の告知を出す。大会終了後は自動で元に戻す。

## 決定事項

| 論点 | 決定 | 理由 |
|---|---|---|
| ファーストビューの扱い | 既存のキャッチ（未来のアスリートを ここ上越から。）は**変更しない**。最上部に告知バーを追加する | 入会希望者への導線を保ったまま告知できる |
| 割り込みの形式 | ポップアップは出さず、**既存のオープニングアニメを期間中だけ大会仕様に差し替える** | 既にオープニングで一度待たせているため、二重の割り込みを避ける。本文を覆うポップアップはモバイル検索での評価低下の対象になりうる |
| 表示期間 | 日付による2段階の自動切替 | 手動での切り忘れを防ぐ |
| カウントダウン | 入れない | 締切まで84日ある時点で「あと84日」は訴求にならない。日付明記のほうが申込判断に役立つ |
| オープニングの絵 | 冬の上越 × 卓球の躍動感。**Codexに制作を委譲** | 12月・豪雪地帯という条件がこの大会固有の絵になり、既視感を避けられる |
| オープニングの文字 | 画像に焼き込まず、**HTML/CSSで組む** | 文言の切替が必要、画面幅に追随できる、検索エンジンと読み上げソフトが読める |

## 表示仕様

### 1. 告知バー（トップページ最上部）

ヘッダーの上に配置する。クリックで `jstyle-cup.html` へ遷移。右端の×で閉じられ、閉じた場合はそのセッション中は再表示しない（`sessionStorage`）。

| 期間 | 文言 | 配色 |
|---|---|---|
| 〜 2026-11-13 | 第2回 J.STYLE杯 参加チーム募集中｜12/26・27 開催／申込締切 11/13（金）必着 | ピンク系グラデーション |
| 2026-11-14 〜 2026-12-27 | 第2回 J.STYLE杯 まもなく開催｜2026年12月26日（土）・27日（日） 上越市総合体育館 | 青系グラデーション |
| 2026-12-28 〜 | 非表示 | — |

### 2. オープニング（大会仕様）

既存のオープニング（`#opening-overlay`）の表示内容を、期間中だけ差し替える。既存の挙動は維持する。

- 1セッションに1回のみ（`sessionStorage` の `opening-seen`）
- タップでスキップ可能
- `prefers-reduced-motion` が有効なら表示しない
- 大会期間終了後（2026-12-28以降）は従来のJ.STYLEロゴのオープニングに戻る

構成要素は、Codexが制作した背景画像の上に、HTMLで次を重ねる。

- ラベル「TOURNAMENT」
- 大会名「第2回 J.STYLE杯」
- 会期「2026.12.26 SAT — 12.27 SUN」
- 会場「上越市総合体育館・身障者体育館」
- スキップ導線

タイポグラフィ（書体・字送り・配置）は、背景画像が上がってから決める。現在のオープニングで使っている白→ピンクのグラデーション文字は使わない。

### 3. 日付制御

`config.js` に設定を追加し、`script.js` が現在日時と比較して状態を決める。

```js
window.JSTYLE_CONFIG = {
  microcms: { ... },          // 既存
  cupPromo: {
    entryDeadline: '2026-11-13',   // この日まで「募集中」
    eventEnd:      '2026-12-27',   // この日まで「まもなく開催」
    cupUrl:        'jstyle-cup.html'
  }
};
```

判定は端末のローカル時刻で行う。時刻のずれによる1日程度の差は許容する（申込は必着期限であり、サイトの表示が受付の可否を決めるわけではないため）。

## 変更対象

| ファイル | 内容 |
|---|---|
| `index.html` | 告知バーのマークアップ、オープニングの大会仕様マークアップを追加 |
| `config.js` | `cupPromo` 設定を追加 |
| `script.js` | 期間判定、バーの表示・閉じる処理、オープニングの出し分け |
| `style.css` | 告知バーと大会仕様オープニングのスタイル |
| `assets/` | Codexが制作する背景画像 |

## スコープ外

- トップページ以外（`news-list.html`、`contact.html` など）への告知バー設置
- `jstyle-cup.html` への告知バー設置（既に大会の情報を扱っているページのため不要）
- microCMSへのお知らせ投稿
- カウントダウン表示

## 検証

- 3つの期間（募集中／まもなく開催／終了後）を、端末の日付ではなく設定値を差し替えて確認する
- モバイル414px・デスクトップ1440pxで横方向のはみ出しがないこと
- ×で閉じた後、リロードしても再表示されないこと
- `prefers-reduced-motion` 有効時にオープニングが出ないこと
- 告知バーがヘッダーやページ内ナビの固定表示と干渉しないこと
